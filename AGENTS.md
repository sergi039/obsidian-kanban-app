# Agent rules — obsidian-kanban-app

- The rules below are for the owner's install on the Mac mini. A personal install on
  someone else's Mac follows [docs/personal-install.md](docs/personal-install.md) only.
- Calendar events for cards: boards `vs` → the work Outlook calendar of `s@virtosoftware.com`
  through Microsoft Graph (the VSDB app); `private` / `cervantes` → the personal Google
  calendar `s@sinyugin.com`. Procedure: `~/Skills-runtime/docs/kanban.md`; routes, credentials
  and client differences: `~/Skills-runtime/docs/data-access-map.md`; rule `rules/common/data-access.md`.
- The owner has one work mailbox and tenant, `s@virtosoftware.com`; mail links in cards point
  there (Graph ids), never to Outlook Web or Gmail.
